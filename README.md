## 📌 Overview

A personal portfolio website designed to showcase projects, technical skills, education, achievements, and contact information through a modern and interactive user experience.

## ✨ Features

- 🎨 Modern UI with custom background effects
- 📱 Responsive design for different screen sizes
- ⚡ Smooth animations and page transitions
- 🖱️ Custom cursor and interactive elements
- ⏳ Animated loading screen
- 📊 Scroll progress indicator
- 💻 Dedicated projects and skills sections
- 🎓 Education and achievements showcase
- 📬 Contact section with social links
- 📄 Downloadable resume
- ⬆️ Back-to-top functionality

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Next.js 16 | React framework |
| React 19 | UI development |
| TypeScript | Type safety |
| Tailwind CSS 3 | Styling |
| Framer Motion | Animations |
| Lucide React | Icons |
| clsx & tailwind-merge | Utility class management |

## ⚙️ Getting Started

### Prerequisites

- Node.js 22.x
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/TanyaVaish-17/tanya-portfolio.git
```

2. Navigate to the project directory:

```bash
cd tanya-portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Visit **http://localhost:3000** to view the application.

### Production Build

```bash
npm run build
npm start
```
